I Ching hexagram generator

The traditional three-coin method: throw three coins six times to build a six-line hexagram from the bottom up, then read which of the 64 classic hexagrams it is. Two versions to compare:

  • Claude version Six empty lines; each throw shows its three coins and draws its line straight away. Changing lines turn red, and the result shows the hexagram it changes to, with read-aloud. /claude-iching
  • Copilot version The original: one throw per page load, then the resulting hexagram. /pyching

Try the weather endpoint

Calls this server's /weather?lat=53.41&lon=-2.15, which asks Open-Meteo for the current weather and adds a plain-English description.

Pick a place or enter coordinates, then press Get weather.

Endpoints

  • /This page (HTML)
  • /statusJSON status: checking…
  • /weatherJSON weather for lat and lon
  • /claude-iching/throwJSON: one throw of three coins

How it's built and run

  • Flask: main.py holds the home page, status and weather; the I Ching pages are a separate blueprint in iching.py.
  • Built from source with Google's buildpacks (no Dockerfile) and deployed to Cloud Run in europe-west1.
  • Cloud Run starts copies of the server only when requests arrive, capped at 2.
  • Cloud Run console (owner sign-in)
